# Responsi 1: Dashboard Manajemen Inventaris Barang Gudang

Aplikasi Dashboard Admin interaktif berbasis web untuk manajemen inventaris barang gudang yang dibangun menggunakan **React 19 (Vite)** dan **Bootstrap**. Proyek ini dikerjakan sebagai bentuk pemenuhan tugas Responsi 1 Pemrograman Fullstack.

## Fitur Utama
1. **Dashboard Statistik:** Menunjukkan ringkasan total jenis barang, total akumulasi stok, serta jumlah barang dengan status stok menipis/habis.
2. **Manajemen Data (CRUD):** 
   - **Create:** Menambahkan data barang baru dengan status stok otomatis (Aman, Menipis, Habis).
   - **Read:** Menampilkan daftar inventaris barang di dalam tabel responsif Bootstrap.
   - **Update:** Mengubah/memperbarui informasi data barang yang sudah ada.
   - **Delete:** Menghapus data barang dari daftar inventaris.
3. **Desain Responsif:** Tata letak disesuaikan dengan standar UI/UX modern menggunakan Bootstrap CSS.
